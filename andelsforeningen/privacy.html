Privatlivspolitik

Andelsforeningen MCP er et internt værktøj for bestyrelsen i A/B Ægirsgade 50-52/Nannasgade 16 (CVR 32638120). Kontakt: bestyrelsennannasgade16@gmail.com.

Hvilke data

Med samtykke fra foreningens egen Google-konto læser værktøjet mails og vedhæftninger i den konto (Gmail-scope gmail.modify). Det kan også oprette kladder, sende svar og sætte labels, når et bestyrelsesmedlem beder om det. Værktøjet sletter aldrig mails permanent.

Hvor data opbevares

Data gemmes lokalt på bestyrelsens egen computer. Data sælges, deles og bruges ikke til reklame. Når et bestyrelsesmedlem stiller et spørgsmål via sin AI-assistent, sendes de relevante uddrag til den AI-udbyder, som bestyrelsesmedlemmet selv bruger. Data kan også sendes til en AI-model, der bruges til at sortere og opsummere foreningens egne mails.

Brug af Google-data

Brugen af data fra Google API'er overholder Google API Services User Data Policy, herunder kravene om begrænset brug (Limited Use).

Tilbagekald og sletning

Adgangen kan tilbagekaldes når som helst på myaccount.google.com/permissions. Lokale data slettes på anmodning til kontaktadressen ovenfor.

English summary: Internal tool for a Danish housing cooperative's board. It reads the cooperative's own Gmail account with the owner's consent, stores the data locally, never sells or shares it, and complies with the Google API Services User Data Policy including Limited Use. Access can be revoked at myaccount.google.com/permissions.
